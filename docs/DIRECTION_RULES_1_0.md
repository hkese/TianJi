## 時間及排序

1. 24／72／168 小時是從本次搜尋 UTC 起點往後的實際時長，非當地曆日數；限期較早時截短。
2. 逐個民用奇數整點、時區 offset 轉換、實際交節及交節緩衝邊界分段。DST 重複時刻保留兩個 UTC 候選，缺失時刻不硬補。
3. 每個候選都保存該段起點的獨立 canonical Core 盤；起念盤另外保存。窗口為 `[start, end)`，用途明定為出發時刻。不是到達或返回吉時。
4. 依時間先後、相同時段依宮號先後，最多三個。不是效力分數、成功率或最優排序。零個匹配是一個正常結果。

## 行程與位置

- 用戶揀「步行出發」或「只看方位」。只看方位不是完成出行法。
- 步行流程記錄準備、出發、到達、返程、完成；已開始的行程可在原出發窗口結束後繼續記錄，未開始則禁止用過期窗口出發。
- 不另停留或 5／10／15 分鐘停留是用戶安排。計時從手動確認到達的時間開始；可以提早返程，不把分鐘數當作古法。
- 出發點是固定基準。選用單次定位會記錄起點及到場位置，皆只存手機；拒絕定位不妨礙查看盤面與方位。
- GPS 相對位移採球面距離及初始真方位角。八方區間用中心角正負 22.5 度作產品地理表示，非新增術數規則；接近定位精度的位移不確認方向。
- 指南針無位置時顯示磁北；有定位時用 Android GeomagneticField 估算真北修正。它不是室內精密測量或道路導航，沒有位置／感應器時明示限制。
- 不虛構可通行的目的地、不自動推城市、不生成手勢步數、返回吉時或回家坐向。目的地由用戶選擇；實際支出與往返可行性需本人判斷。
- 廣東話播報只選已安裝、無需網絡的廣東話語音；缺少時給文字指引，不在背景下載或改用雲端。

## AI 與歷史相容

新版手動提示詞只解說時段及方位行程；舊版一般實用方案保留為歷史。AI 不增加計算、路線、儀式數字或保證。起點／到場坐標及日誌筆記不包含在手動 AI 匯出。

既有 JSON 預設欄位保持相容。新增行程保存在原 action payload，沒有替換舊表。備份會包含用戶選擇記錄的位置，應視為私人資料；研究匯出不包含座標。
