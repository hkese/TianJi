# 天機：擇時、擇方與方位行動修訂

日期：2026-10-13。狀態：需求更正及規則調查；尚未實作或交付新版 APK。

## 已確定的產品方向

使用者需要由當下心願，獲得按奇門規則產生的時空行動安排：何時出發、向哪個方位、到哪裏、到場做甚麼、何時離開、返回後的位置或朝向。畫面和語音需要用自然香港繁體中文逐步帶領。

0.4.0 的工作、學習、溝通與日常三方案，是產品自訂的一般行動建議。即使附上真實盤面的方位，也沒有達成這個需求。這是產品理解錯誤，不能用換文案、換提示詞或把一般建議改標 TRADITIONAL 當作修正完成。

本修訂補充原始 v3.0 規格；原文件保留。實際問事內容、關係資料、使用者貼出的 chart/context 與位置不得作為公開範例或測試 fixture。

## 預定使用流程

1. 輸入心願；選擇「現在／今晚／指定日期」、可用時間、原位／步行／駕車及可接受距離。時區選城市，不輸入 IANA 字串。
2. 清楚選定一套有來源的擇時擇方方法。首次介紹一次，之後記住。起念問事盤與各候選行動時段的盤分別儲存，不能用現在盤假冒未來盤。
3. 展示符合方法與限制的候選安排；不足三個就顯示實際數目與原因，不為湊數虛構吉方。
4. 選定後顯示一張行程卡，再逐步顯示／播報：準備、出發、到達、當地動作、離開／返回、結束。支援暫停、跳過、過期重新計算。
5. 完成後先記錄實際做了甚麼，再另記心願的後續觀察。完成行程不等於心願必定實現。

### 行程卡必要欄位

| 欄位 | 產生方式與驗收要求 |
|---|---|
| 出發／到達時段 | 確定規則作用於出發還是到達；引用對應 Core 盤及當地時區，處理跨時辰、子初、交節與 DST |
| 方位與基準點 | 說明相對於出發點、家居中心還是當下位置；固定基準，不因走動而偷偷改變 |
| 實際目的地 | 來自本人選定地點或可核實的地圖資料；列實測／計算方位及距離；不能從宮名憑空生成城市 |
| 朝向與所在位置 | 「坐在某方」與「面向某方」分開顯示；不可互相代換 |
| 動作、步數、停留 | 每項傳統要求附 rule_id、來源與適用條件；沒有規定則寫明，不補一個聽起來神秘的數字 |
| 返回時間 | 若只是本人可用時間，標示行程安排；若聲稱傳統擇時，必須另有已核對的規則與盤 |
| 依據 | 可展開檢視門、星、神、干、格局、取用原因、排除條件及規則版本 |

以上是介面契約，不是已計算的行程。沒有在此文件填入虛構鐘點、地址、方向或動作。

## 已查到的原始資料與尚未解決的差異

閱讀日期：2026-10-13。

- D1／既有 R1：《煙波釣叟歌》，固定版本 https://zh.wikisource.org/w/index.php?title=煙波釣叟歌&oldid=1336835 。有奇、門、神配合及擇向內容，也同時列出伏反吟、擊刑、入墓、門迫等檢查。只找到吉門便給出最佳出行方向，並不等於完成這些條件。
- D2／R7：《遁甲演義（四庫全書本）》卷二，固定版本 https://zh.wikisource.org/w/index.php?title=遁甲演義_(四庫全書本)/卷2&oldid=625940 。「人遁」章以丁、休門及太陰組合立論，涉及和合用途，並載出行轉向、步行數目和手部書字的用法；「玉女守門」則有另一組值使與丁的條件。這證明所需動作類型在文獻中有記載，不代表隨便拼接便成為一個可執行或有效的方案。

不能直接把 D2 的每段文字套入現有轉盤資料。需要核對天／地／神盤的指稱、原文例局、中宮寄法及動作適用範圍；古文的轉向描述也不能直接當成現代道路路線。文獻存在、計算吻合與實際成效是不同的驗證事項。

出生資料暫不自動加入。現有 Core 是事件時刻的時家盤；若選定的方法需年命或其他個人資料，再明確定義用途、所需欄位與處理規則。不得把生日加入 prompt 就聲稱完成個人命盤。
