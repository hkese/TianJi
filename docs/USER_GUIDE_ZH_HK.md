# 天機使用說明（繁體中文・香港）

適用版本：0.3.0。App 內「首頁」及「設定」都有「使用教學」，毋須連網。

## 先了解現有功能

目前可使用：離線奇門九宮盤、中文傳統簡讀、已存盤、目標、三個實用行動方案、日誌、重新規劃及備份。

奇門排盤採固定的「時家轉盤拆補」，直接在手機計算。簡讀是傳統象意參考，唔係科學預測，唔會保證成敗。100 個獨立人工金標目標仍未完成；吉時日曆及進階格局未開放。目標頁的三個方案是另外的實用規劃。

## 最快用法：三步起盤

1. 底部按「奇門」。確認畫面城市係你要用嘅時區。
2. 按「用現在時間起盤」，即刻睇「本盤簡讀」。毋須出生日期、GPS、連網或 AI。
3. 想了解依據，點九宮看門、星、神、天地盤干；想留低，按「儲存此盤」，之後在「已存盤與歷史」重開。

盤面會固定在你揀嘅時間，唔會睇緊突然跳盤。要更新，就再按現在時間。要查過去或未來時刻，按「改日期／時間／時區」，從月曆及時鐘選擇，揀好即重新計算。計算未來日期的盤，唔代表知道嗰日會發生乜事。

九宮南在上、北在下；深色邊框的事情宮提供本次簡讀。簡讀只看時干落宮的八門象意，未綜合全盤。死門、傷門等是傳統名稱，不是死亡或受傷預告。兩個天干以「、」分隔時，後者是中五寄干。

支援 1900–2100 年；採所選城市的民用鐘面時間、23:00 換日，無真太陽時校正。夏令時間跳過的時刻會要求重選；回撥時出現兩次的時刻會讓你揀第一次或第二次。與其他流派、午夜換日或真太陽時軟件比較，盤面可能不同。

## 1. 選時區

首次開啟或到「設定」按「時區」，直接選城市。常用選項包括香港、西雅圖／洛杉磯、溫哥華、台北、北京／上海及紐約。

- 西雅圖／Renton：選「西雅圖／洛杉磯（美國太平洋時間）」。
- 香港：選「香港」。
- 不確定：選「使用手機目前時區」，不需 GPS。
- 可用中文或英文搜尋城市，亦可在列表直接選擇，毋須輸入時區代碼。
- 夏令時間按各城市規則自動換算，不是固定 UTC 差。
- 新安裝預設用手機當時的時區；升級保留你之前的選擇。
- 「使用手機目前時區」會儲存當時的選擇；旅行後可再按一次。
- 更改時區不會改動已儲存行動的實際時間，只改變顯示及新計劃所用時區。

## 2. 建立目標

「目標」→「新增目標」。先填「目標名稱」及「怎樣算完成？」。

例子：名稱「今晚讀一頁書」；完成標準「寫低一句重點」。限期可不填，其餘先用預設值。按「儲存目標」。可加入里程碑，把較大的目標分開做。

## 3. 比較並選擇行動

按「規劃下一步」→「產生三個方案」。你會見到：釐清完成標準、做一個最細步驟、檢視阻力與下一步。

這是三種不同做法，選一個便可，毋須全部做。它們共用一個按可用時間及限期安排的時段，並非三個吉時。現時方案支出為零；文字限制仍需自行核對。限期已過時，先編輯目標再產生方案。

## 4. 記錄結果及重新規劃

在已選方案按「記錄結果」，選完成／部分完成／未完成／未知，可加評分及筆記，再按「儲存日誌」。

如果情況有變，返回「規劃下一步」，填寫新觀察，再按「重新規劃，保留歷史」。舊計劃不會被覆蓋。達成整個目標後，可到「編輯」將狀態改為「已完成」；日誌不會自動完成整個目標。

## 備份、提醒與可選 AI

- 「設定」可匯出 JSON 備份。匯入會取代現有記錄，建議先備份。
- 提醒預設關閉；開啟後約每 12 小時提醒，22:00–08:00 為安靜時段，按所選時區計算。手機系統可能延後通知。
- 起盤、簡讀及離線規劃全部毋須 AI。進階設定中的 AI 需要你提供供應商，每次分享目標及方案前都會要求確認。
- 研究匯出由你主動選擇，不會自動上傳。
- 傳統奇門、研究假說及軟件測試，都不等於經科學證實的個人預測。
