# 天機 0.5 使用說明

1. 安裝 0.5 更新檔，可覆蓋 0.4「天機・行動導航」，保留現有資料。更早的另一個套件仍須先匯出再匯入備份，不要刪除唯一有資料的舊 App。
2. 在設定直接選城市時區；西雅圖選「西雅圖／洛杉磯」，無需輸入時區代碼。
3. 到目標寫低心願及日後觀察標準，儲存後按「規劃下一步」。
4. 選「一般出行」或「和合相處」，再選 24 小時、72 小時或 7 日。按搜尋，查看最多三個按時間先後排列的候選。每個候選有自己的時段盤、門星神干及匹配理由。
5. 沒有匹配會明講，不會硬配方向。可擴大搜尋範圍，亦可稍後再查；沒有候選不等於心願不可能達成。
6. 選定後頂部顯示目前階段。出發窗口以外不能按「開始出發」。從固定起點，在選定方位找一個本人知道可安全到達的目的地；箭嘴不是道路導航。
7. 手機平放看指南針。「定位起點」及「定位到場位置」均是選用；只取當次位置並留在手機。不授權仍可使用盤面及方位。沒有定位只顯示磁北，有定位才估算真北修正。接近定位誤差的位移不確認方向。
8. 按出發、到達、返程、完成來記錄行程。到達後的 不另停留或 5／10／15 分鐘是自己揀的停留安排，沒有古法吉數含義，可以提早返程。重開 App 會恢復已記錄階段。
9. 「讀出呢一步」使用已安裝的離線廣東話語音。沒有語音則繼續看文字；可自行在 Android 文字轉語音設定下載語音。
10. 完成行程後另按「記錄心願結果／觀察」，揀完成、部分、未完成或未知。完成出行並不自動等於心願實現。
11. 想問 AI，可複製行程提示詞，貼入 ChatGPT／Codex。預览包含目標、限制、候選盤和規則，沒有 GPS／金鑰／日誌筆記；AI 回覆不會自動寫回 App。
12. 想改計劃，填新觀察並重新擇時。過去版本及舊版實用方案會保留為歷史。

本版沒有地圖道路導航、自動城市／地點選擇、出生盤、儀式手勢步數、返回吉時或回家坐向。只看方位模式不需出行，但不代表完成古籍出行法。完整規則與局限可在行程內展開查看；傳統用途不保證實際結果。

備份包含你選擇記錄的位置，請私人保管。匯入會取代目前資料；先匯出現有備份再決定是否取代。研究匯出不包含座標。
