# 天機・行動導航 0.4 使用方法

這個版本由「想做甚麼」開始，會離線起一個當刻問事盤，給三個有步驟的做法。毋須出生資料、GPS 或 API 金鑰。

## 安裝及舊資料

新版顯示名稱是「天機・行動導航」，套件是 `com.tianji.navigator.daily`。它與舊「天機 · TianJi」並排存在，毋須刪除舊版。舊版簽署私鑰在先前暫存環境清理後遺失，所以這次不能聲稱可直接覆蓋更新。

如要搬記錄：先在舊版「設定」匯出 JSON 備份，再在新版「設定」匯入。匯入會取代新版現有記錄；先搬資料，再開始建立新目標。語言、時區、提醒及 AI 供應商設定需重新選擇，API 金鑰不在備份內。

## 每日使用：五步

1. **選時區**：首次開啟直接揀城市，或者「使用手機目前時區」。旅行後可在設定重選。
2. **寫目的**：「目標 → 新增目標」，揀工作／學習／溝通／日常，填想達成的事及「怎樣算完成」。描述可寫背景、對象及你手頭已有的資源。設定今次可用分鐘；限期可不填。
3. **產生三個方案**：「規劃下一步 → 產生三個方案」。App 用現在時間起盤，三張卡各有適用情況、時段、門星神／可選象意方位、三個操作步驟及完成證據。三個是不同做法，選一個就夠。
4. **照住做**：按「選擇此方案」，畫面會回到最頂的「即刻做呢一步」。首頁亦顯示第一步。方位只是傳統參考，可以用手機指南針辨識；不用特登出行，原位做亦可以。App 不測量你的位置。
5. **記錄再調整**：按「記錄結果」，揀完成／部分／未完成／未知。返回方案，填新觀察後重新規劃。舊版本會保留原來盤及目標。原定時段已過就按「用現在時間重新規劃」。

例如目的係學習「讀懂一頁課文」：三個做法係讀一小段寫重點、做一題核對、準備一條請教問題。每張卡都列出如何做、怎樣檢查完成，不需要你先識解盤。

## 交給 ChatGPT／Codex 做更個人化分析

在三方案下面按「交畀 ChatGPT／Codex 分析」。先檢視分享內容，按「複製完整提示詞」，再開 ChatGPT 或 Codex 對話，貼上並送出。這個手動方法毋須在天機設定 API 金鑰；使用對方服務仍由你的帳戶及服務本身決定。

提示詞包含本計劃的目標／描述／限制／改計劃原因、完整九宮盤、三方案、選擇狀態及本計劃已記錄的結果。它不包含日誌筆記、其他目標、API 金鑰或 GPS。提示詞要求 AI 分清盤面事實、傳統解讀、實際步驟，逐項回答幾時、方位、做乜、點做、完成證據及檢視時間。AI 不可另作排盤，原盤過時要提示返回天機更新。

回覆不會自動匯入 App。看完後返回天機選最合適的方案，把有用觀察寫入「新觀察」再重新規劃。AI 仍可能出錯，盤面資料以本機 Core 為準。

## 盤、用神、方位各代表甚麼

「用神」指針對問題選用的觀察符號，並非召喚神靈。本版用天盤時干所在宮作事情觀察點；三種行動另外以開／景／生／休門作簡化象意配對。每張卡所列宮、门、星、神都是同一實際盤的資料。具體做法由 App 依目的編排，不是全盤吉凶判斷。

本版是民用時區、時家轉盤拆補、中五寄坤二口徑；沒有真太陽時校正，未加入空亡、馬星、旺衰與十干格局綜合斷事。行動時段按可用時間安排，不是吉時。傳統奇門與 AI 解讀的預測效果並未獲科學證实，不保證結果。
