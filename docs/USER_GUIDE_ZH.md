# 天機 0.6.1：寫低心願，就有指引

1. 打開首頁，在「我想……」寫低心願。
2. 按「畀我奇門指引」。天機自動起盤、取用及搜尋，直接顯示本機簡讀和一份符合條件的方位指引。
3. 要指南針及出發／到達／返回記錄，按「打開方位指引」。

## 直接用 ChatGPT／Codex 解讀

首頁按「連接 ChatGPT／Codex」→「登入 ChatGPT／Codex」。App 會開啟 OpenAI 登入頁；輸入天機顯示的一次性代碼，完成授權後返回天機。帳戶可能需要先在 ChatGPT 安全設定開啟裝置碼登入。密碼只在 OpenAI 頁面輸入。

登入後會自動取得帳戶的模型清單。啟用 ChatGPT 解讀後，每次按「畀我奇門指引」就會把當次心願及盤面傳送去解讀，結果直接出現在天機，毋須複製提示詞。模型及使用額度以你帳戶為準；可在同一頁更改模型、更新清單或登出。

0.6.1 登入時，短暫斷線會顯示目前階段並自動重試，保留同一個未過期代碼；返到天機毋須重開登入頁。App 被系統回收後，未完成授權會自動恢復。若你按「取消連接」、代碼過期、授權被拒絕或憑證回傳已失效，則需要開始新授權。登入成功但模型清單更新失敗，可按「更新模型清單」，毋須重新登入。

如果由 0.6.0 更新，而舊登入已經顯示失敗，請在新版按「登入 ChatGPT／Codex」完成一次新授權；舊版沒有保存失敗登入的待完成資料。

沒有網絡、登入失效、額度用完或 AI 回覆未完整，已計好的本機指引會保留。可以取消等候、重試解讀，或改回本機模式。天機不會讀取鍵盤 App 的登入資料，第一次需要在天機獨立授權。

已有 API 金鑰亦可用：在設定儲存 HTTPS 供應商、模型及金鑰，再於連接頁選「用已設定 API」。這條路徑按供應商帳戶計費，與 ChatGPT 帳戶登入分開。

## 只在有需要時改設定

- 「進階選項」可以揀城市時區、改自動取用或搜尋範圍；西雅圖揀「西雅圖／洛杉磯」。不用打時區代碼。
- 自動取用是 App 文字分類：和合／相處類字詞用人遁或玉女守門，其他使用一般出行簡式。分類可改，並非全套專業占斷。
- 「今晚」按所選時區的 18:00 至午夜安排搜尋；「明日」按翌日。沒有日期就查未來 24 小時。這是文字時間安排，不是把 18:00 當成吉時；複雜日期句子未作完整自然語言理解。
- 沒有符合條件就明講。不能用另一用途硬配方向，沒有候選也不等於心願不會實現。AI 仍可解讀當時的起念盤。
- 出發時間、方向及操作卡以手機計算為準；AI 文字是未驗證的傳統解讀，不能改造盤面或保證結果。
- 目的地由你按現實道路選擇；指南針不是地圖導航。預設行程預算 20 分鐘、不另停留，均是時間安排，並非古法吉數。
- 舊版多方案、目標、日誌、盤面和教學保留在「進階／歷史」及原有分頁。

## 更新及私隱

這次 0.6.1 同簽署 APK 可以直接更新 0.4／0.5／0.6「天機・行動導航」，不要先解除安裝。更早的 `com.tianji.navigator` 是另一個套件，需要自行匯出再匯入 JSON 備份。

ChatGPT 授權及 API 金鑰由 Android Keystore 保護，沒有放入備份或研究匯出。AI 只收到當次心願及相關盤面，不會收到 GPS、其他心願或日誌。私人備份會包括你選擇記錄的位置，請妥善保存；匯入會取代目前記錄。

本版沒有出生盤、自動城市選址、儀式手勢步數或返回吉時。奇門屬傳統參考，不保證心願實現。
