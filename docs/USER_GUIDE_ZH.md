# 天機 0.7：直接跟指引

1. 首頁撳 **「直接畀我指引」**。唔寫任何嘢都可以查今日趨吉避凶。
2. 睇最上面 **「下一步」**：幾時出發、向邊個方位、點樣行。顯示「先等到」就未出發；過時就重新整理。
3. 撳 **「開指南針，跟住行」**。行程已選好，到時按「開始出發」，到場按「我已到達」，之後按自己安排返回並記低結果。

有一件特定事情，按「有一件事想問」，寫一句再查就得。AI 已連接會直接喺 App 加解讀；未有網絡亦有本機指引，毋須再複製提示詞。

「同一時段先避用」列出本次出行簡式排除的方向，只適用上面出發時段。想知盤據就按「睇盤面同依據」，不是把所有未選方向當凶方。今日未有匹配，就按「睇下一個可用時段」查未來七日；實際日期會寫清楚，不會當成今日。

首頁有城市時區；要改就按「時區及進階選項」揀城市。西雅圖選「西雅圖／洛杉磯」，不用輸入時區代碼。舊記錄在「進階／歷史」。

0.7 同簽署 APK 可直接更新 0.4–0.6.1，不要先解除安裝。原有登入、心願、盤及日誌會沿用；更早的 com.tianji.navigator 是另一個套件，需要自行匯出再匯入備份。

登入的短暫斷線恢復、加密待完成授權及模型更新重試保留。AI 僅收到當次心願及盤面，不傳 GPS、其他心願、日誌或憑證。指南針不是道路導航；未有自動城市選址、出生盤、手勢步數或返回吉時。奇門屬傳統參考，唔保證效果。
